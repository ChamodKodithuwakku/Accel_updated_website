# Speaker Photos Folder

Place all portrait/headshot photos of Keynote Speakers, Judges, and Mentors in this folder (`public/speakers/`).

### How to use:
1. Save your photos here (e.g. `dr-malik.jpg`, `ananya-sharma.jpg`, `kasun-perera.jpg`).
2. Open `src/data/speakersData.js`.
3. Set the image path:
   ```javascript
   {
     id: 1,
     name: "Dr. Malik Fernando",
     image: "/speakers/dr-malik.jpg", // Path to this file
     // ...
   }
   ```

### Recommended Image Specs:
- **Aspect Ratio:** 1:1 Square or 4:5 Portrait (e.g. 600x600 px or 600x750 px)
- **Formats:** `.jpg`, `.jpeg`, `.png`, `.webp`
