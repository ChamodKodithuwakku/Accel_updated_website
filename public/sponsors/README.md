# Sponsor & Partner Logos Folder

Place all corporate sponsor and ecosystem partner logos in this folder (`public/sponsors/`).

### How to use:
1. Save brand logos here (e.g. `dialog-logo.png`, `virtusa-logo.png`, `wso2-logo.png`).
2. Transparent PNG or SVG formats work best against dark and light backgrounds.

### Recommended Image Specs:
- **Format:** Transparent `.png` or `.svg`
- **Height:** 80 - 150 px
